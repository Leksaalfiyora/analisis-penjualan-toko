# Analisis Data Penjualan Toko

## Deskripsi
Program ini merupakan studi kasus analisis data penjualan toko sederhana menggunakan Python. Program digunakan untuk menghitung total pendapatan, pendapatan setiap produk, dan menentukan produk dengan jumlah penjualan tertinggi.

## Tujuan
- Memahami pengolahan data menggunakan Python.
- Menghitung pendapatan dari data penjualan.
- Mengetahui produk dengan jumlah penjualan tertinggi.
- Menerapkan analisis deskriptif dan tahapan awal CRISP-DM.

## Teknologi
- Python
- Visual Studio Code

## Cara Menjalankan
1. Pastikan Python sudah terpasang.
2. Buka terminal pada folder proyek.
3. Jalankan perintah `python analisis_penjualan.py`.

## Hasil Analisis
- Total pendapatan: Rp181.000
- Pendapatan Buku: Rp75.000
- Pendapatan Pulpen: Rp60.000
- Pendapatan Pensil: Rp30.000
- Pendapatan Penghapus: Rp16.000
- Produk dengan jumlah penjualan tertinggi berdasarkan jumlah pada satu baris transaksi: Pulpen

## Kesimpulan
Python dapat digunakan untuk mengolah data penjualan dan menghasilkan informasi yang membantu pemilik toko memahami pendapatan serta produk yang banyak terjual.
